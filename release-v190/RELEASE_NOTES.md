# FocusLink v1.9.0

> 发布日期：2026-10-29
>
> 对应提交：`d05fcd5`

> 发布类型：候选补丁

> 验证状态：源码门禁、Windows 与 Xiaomi 安装回读通过；打勾动效、停留与撤销已在小米真机确认

## 主要变化

- **打勾不再“凭空消失”**：勾选完成后任务留在原位 1.4 秒，播放 `tt-check-pop` 弹跳 + 对勾淡入，标题变灰加删除线，然后才按“未完成筛选”移出列表。
- **撤消入口**：完成后底部弹出「已完成「任务名」 撤销」，1.4 秒内可一键还原；撤销条特意避开右下角新建按钮。
- **云端确认前也按已勾选渲染**：本地先把该任务强制画成完成态，避免刷新前后出现“勾了又跳回去”的闪烁。
- 失败回滚：完成请求失败时会撤回刚加的完成态并显示错误，不留假勾。

## 验证

- 源码门禁：`format:check`、`typecheck`、`lint` 均 exit 0；`npx vitest run` **166 文件 / 1424 用例全绿**；`build`、`build:web`、`dist` 成功。
- Windows：静默覆盖安装 → `DisplayVersion=1.9.0`、EXE `1.9.0.0`。
- Xiaomi：`adb install -r` → 回读 `versionName=1.9.0`、`versionCode=1366`。
- 真机确认：点「第四节优先复盘」勾选框后，该行变灰带删除线并保留在列表底部，底部出现「已完成「第四节优先复盘」 撤销」，新建按钮不再遮挡撤销。

## 升级提示

- 本轮只改任务勾选的反馈与动效，不改同步协议与计时。
- 完成后 1.4 秒内点「撤销」即可还原；超时后仍可在「已显示完成」视图里取消。

## 已知限制

- **完成项会移到列表末尾** — 因为按未完成筛选后重新分组，窗口期内它落在末尾而不是原位，视觉上仍可见但位置有跳动。
- **撤销只针对刚完成的一条** — 连续勾选会以最后一条为准。
- 旧样式层迁移期仍被导入（工程债）。
