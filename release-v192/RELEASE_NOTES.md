## 主要变化

- **任务页成为完整工作台**：顶部搜索（标题/标签实时过滤、可清除）、批量选择（完成 / 删除二次确认 / 移动清单）、详情面板新增子任务，全部入口都有处理中态、行内错误与不阻塞关闭的返回路径。
- **离线动作全打通**：还没同步的新任务也能勾选、改字段、加子任务、删除——先落在创建记录上，创建成功后自动补交完成；移到清单改走本机编辑队列，断网也能排队。
- **专注页**：选任务、输入名称、直接开始三条入口齐全，输入名字即可直接开始；运行与暂停时主控制位置固定不抖位。
- **统计页**：今天做了什么、各任务投入多久、暂停与空档在哪，三个回答前置到时间轴之前；空态换成一句人话。
- **设置页**：同步范围合并为一张卡，帮助说明并入版本块。
- 修掉一类脏队列：目标已不在云端的编辑/删除记录会被直接丢弃，不再反复报 409。
