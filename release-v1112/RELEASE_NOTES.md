## 主要变化

- **修「58 分钟专注只记 21 分钟」**：实时同步模式断线后，远端快照的专注时长冻结在最后一次成功拉取；结束专注时旧实现把这个冻结值直接落账，自然跨度却按真实时间计算。现在接管快照时会按 `now - lastTick` 补齐断线期间的运行时长，并以「真实跨度 - 暂停」为上限取小，同一增量也写入未结束分段，会话与分段不再互相矛盾。
- **受影响记录已修正**：`db19414b-e91e-4e08-8198-64e294689a1b` 的专注时长由 21.05 分钟改为 58.56 分钟（1,263,330ms → 3,513,747ms）；改前已备份数据库。
- **回归覆盖**：新增「接管断线快照补齐时长」用例，断言结束时会话时长贴近真实跨度、暂停为 0、分段之和等于会话。

## 升级提示

- 已安装版本可直接用安装器静默覆盖；升级后建议打开历史页核对最近一场长专注的时长与自然跨度是否一致。
- 若仍在使用实时同步且中途断网，结束专注会在本机完成并在重连后按同一 id 收口，不再丢时长。

## 已知限制

- 打包版「实时权威断网收尾」仍没有真机 E2E：canonical 设备令牌被强制路由官方端点，legacy loopback 凭据启动即被迁移销毁，官方端点在本机 TLS 不可达；证据为真实 `TimerManager` + 真实控制器 + 内存库 + fetch 桩的用例。
- 任务列表虚拟化未做（仅 `content-visibility`），超大任务集滚动仍走全量 DOM。
- 本轮按 PC-only 指令未做小米/华为装机回读，移动端同版本构建仅作备份。
