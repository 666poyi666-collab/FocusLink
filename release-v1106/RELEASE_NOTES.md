# FocusLink v1.10.6

> 发布日期：2026-11-08
>
> 对应提交：`a15610d`
>
> 发布类型：候选补丁
>
> 验证状态：源码门禁、打包启动自检、Windows 静默覆盖安装与可见性回读、小米同版安装回读与真机 UI/性能验收通过；华为平板 adb 未授权本轮未安装

## 主要变化

- **任务页去臃肿**：删掉每行常驻的「选择」按钮，批量入口只留长按与右上角菜单；标题恢复整行宽度，行内右侧只剩日期与展开箭头。
- **底部只留一条提示**：撤销条、批量结果、待同步汇总共用同一个位置。v1.10.5 里撤销条和「N 条已存本机」是两条各自定位的黑条，会互相叠盖。
- **底部导航重做**：四项统一 22px 图标 + 11px 标签，激活项只换颜色、不再套蓝底方块，导航顶部补 0.5px 描边。
- **搜索框收成单层**：40px 高、压掉历史重置层给 input 的白底与描边（原来是「框里套框」）。
- **行内状态只在需要时出现**：「待同步 / 同步失败」才显示，同步完成后行恢复干净。
- **新建按钮阴影减淡**：去掉大面积蓝色光晕。

## 验证

- 源码门禁：`format:check`、`typecheck`、`lint` 全部 exit 0；`npm test` **181 文件 / 1580 用例全绿**；`dist` 成功；`verify:packaged` 通过（version=1.10.6，对应提交 a15610d）。
- Windows：静默覆盖安装 exit 0，卸载注册表 `DisplayVersion=1.10.6`、已安装 EXE `FileVersion=1.10.6`；`smoke:window-visible` 通过（pid 12496，主窗口 handle 非零）。
- Xiaomi：`adb install -r` 后回读 `versionName=1.10.6`、`versionCode=1382`（aapt2 读出的 APK 身份同源）。
- 小米真机实测：DOM 450 → 379 节点；滚动帧 p50/p90/p95 均 8ms、>33ms 帧 0、长任务 0；点勾到勾选生效 40ms → 3ms；底部导航四项标签可见且等高，搜索框单层 40px，行内「选择」按钮数量 0。
- 华为平板：adb 连接停在 `unauthorized`（平板未授权本机密钥），本轮未安装、不计入通过。

## 升级提示

- Windows 用安装器静默覆盖后回读卸载注册表与已安装 EXE 版本，并重新启动应用。
- Android 用同一 APK 执行 `adb install -r`，保留应用数据并回读版本号。
- 批量选择入口变了：现在长按任意任务行，或点右上角「⋮ → 批量选择」。

## 已知限制

- 批量动作仍没有逐条撤销窗，只有 4 秒结果提示；撤销只服务单条勾选。
- 补发依赖前台在线，锁屏或切走后要回前台才同步。
- 华为平板仍未授权，三端同版矩阵本轮缺华为。
