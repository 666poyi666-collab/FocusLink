## 主要变化

- **打勾不再等网络**：勾选只写本机意图（IndexedDB），界面立刻显示「本机已保存」，不再先刷新整份远端清单再提交。
- **6 秒撤销窗口**：窗口内点「撤销」直接丢弃这次意图，云端从未收到，循环任务也不会被推进；窗口结束后行高平滑收拢、周围任务补位。
- **连续勾选互不阻塞**：每个任务独立计时，底部撤销条合并成「已完成 N 项」，失败项单独标红并保留可处理记录。
- **断网也能勾**：断网时完成状态落在本机队列（记录尝试次数与错误码），强杀重开仍在，联网后按序补传；退避 5 秒起、封顶 60 秒，服务端 Retry-After 原样尊重。
- **不重播动画**：只有本次刚勾选的行播放弹跳；打开已完成列表或刷新带出的已勾选行不再重放。

## 升级提示

- Windows 使用安装器静默覆盖后必须回读卸载注册表与已安装 EXE 版本，并重新启动应用。
- Android 用同一 APK 执行 `adb install -r`，保留应用数据并回读 `versionName/versionCode`；不配置 ADB reverse。
- 升级前留在队列里的完成意图会继续补发，不需要手动清理应用数据。

## 已知限制

- 补发依赖前台在线：锁屏或切走应用时补发暂停，回到前台后自动收敛（沿用既有规则）。
- 循环任务的完成推进本轮只有单元测试覆盖，真机未构造循环任务。
- 离线冷启动仍只靠与账号无关的 `taskSnapshot.legacy.v1` 兜底，账号作用域缓存键在本账号下没有写入。
