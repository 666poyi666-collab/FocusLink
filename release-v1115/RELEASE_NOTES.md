## 主要变化

- **看板不再是后台仪表盘**：统计页此前是四格描边 KPI、满宽进度条排行、紫蓝渐变环加默认图表色，和任务页不是一套语言。现在整页按一页纸质台账排：发丝线分行，数字与单位分开，强调色只承担信息。
- **读数分层**：hero 时长按「数字 / 单位」拆开，数字走衬线体、单位降到 0.4em 次级灰；四格 KPI（暂停 / 有效占比 / 关联任务 / 连续记录）从四个描边小盒合成一条带上发丝线的台账，值 16px 等宽 tabular。
- **台账行取代卡片**：重点任务排行与清单分类占比去掉逐行描边盒子，改为透明行 + 上边发丝线，悬停只换 2px 强调左边；进度条压到 2px 并把轨道做实，不再读成数值下划线。
- **分类配色令牌化**：环形图与侧栏分类点原先写死六只 Tailwind 图表色，换色彩基调不跟随。改为 `--alloc-1..6` 令牌（强调色两阶 + 暖沙 + 两级中性灰），环形图、侧栏色点、占比条同源。
- **图表去装饰**：暂停损耗的 135° 斜纹改半透明纯色（柱宽只有几像素时斜纹会糊成噪点）；45 分钟参考线改中性虚线；Y 轴四档各写一遍「分钟」改成一格一次。
- **热力矩阵铺满**：由固定 24 列、总宽约 400px 挤在卡片左侧，改为按卡片宽度均分的 grid，方块等比放大（上限 30px），168 天铺满整块。
- **骨架屏契约不再偶发红灯**：`smoke:stats` 的 `cold load shows skeleton rows` 原先在 showTasks() 后 150ms 采样，而骨架要等 `SKELETON_DELAY_MS = 140` 之后才上屏，10ms 余量取决于 React 提交时机。等待窗口是产品行为，改的是采样时机（320ms），13 条断言全 PASS。

## 升级提示

- 直接运行安装器静默覆盖即可，应用数据与本地账本不动。
- 本版只改统计页的排版与配色，不改任何时长口径；升级后同一个会话在页头、侧栏、环形图、排行与账本上的数字应当仍然一致。
- 若某个自定义主题下分类色看起来偏淡，那是 `--alloc-1..6` 跟随 `--app-accent` 的结果，不是数据问题。

## 已知限制

- 未做高分屏（150% / 200% 缩放）的实机截图核对，只覆盖 1600×1000 与 6 档 smoke 尺寸。
- 右栏会话账本在 38% 高度处滚动裁切是既有行为，本轮只统一圆角与分隔线，没有改层级。
- 移动端统计页未同步这套台账样式（PC-only 轮次）。
