# FocusLink v1.11.0 PC 看板 + 任务页 界面设计提案

> 状态：**设计提案**（仅文档，不改任何代码）
> 基线：v1.10.8（2026-11-21）
> 范围：Windows 桌面 renderer 的「统计看板页」（`src/features/history/`）与「任务页」（`src/features/tasks/`）的视觉语言、布局、动效、PC 专属交互与组件状态
> 演进原则：在 v1.10.8 现有视觉基础上**收敛与调优**，不推翻既有 token 体系、不新增第二套主题、不引入新 UI 框架或运行时依赖

---

## 0. 摘要

v1.11.0 把「丝滑、轻量、不卡顿」从体感落成三样可执行的东西：① 一套收窄为 **120 / 200 / 320ms** 三档的时长梯度 + 四条统一缓动曲线；② 一张「仅 transform / opacity（translate）合成器友好属性」白名单，把 v1.10.8 已验证的「入场用 `translate` 而非 `transform`」约束提炼成通用规则；③ 看板五卡与任务行/胶囊的完整组件状态矩阵（default / hover / active / disabled / loading / focus-visible / selected）。布局层保持三栏任务台与 12 栅格看板骨架不动，只做密度、留白与断点的精确化。

## 1. 视觉语言（token 演进）

### 1.1 色彩

现有语义色板（`src/styles/temporal-foundation.css`，RGB 三元组）继续作为唯一事实源，本提案只做两处演进：**① 明确层级表面 token；② 补齐 hover / press / selected 三档叠加层**。五个强调色（翡翠 / 钴蓝 / 鸢尾 / 琥珀 / 石墨）与主题三态（light / dark / system）保持不变。

**中性表面（亮色，token 现值 → 建议值）**

| Token | 现值 | v1.11.0 建议 | 说明 |
| --- | --- | --- | --- |
| `--app-canvas` | `var(--app-surface-2)` | `244 244 240`（#F4F4F0） | 画布与 surface 分离，层级更清晰 |
| `--app-surface` | `252 252 250` | 不变 | 卡片 / 行默认底 |
| `--app-surface-2` | `240 240 236` | 不变 | 内嵌面 / 分组头底 |
| `--app-surface-3` | `232 231 225` | 不变 | 按下态 / 次级内嵌 |
| `--app-border` | `221 220 214` | 不变 | 1px 发丝边界 |
| `--app-border-strong` | `198 197 190` | 不变 | 强调边界 / 分隔 |

**暗色（token 现值）**：`--app-surface 21 24 28`、`--app-surface-2 29 32 37`、`--app-surface-3 37 40 45`、`--app-text 239 239 235`、`--app-border 47 50 54`、`--app-border-strong 66 70 76`，保持不动，只新增同语义的叠加层 token。

**新增叠加层 token（三档，均从 `--app-text` 派生，不写死黑 / 白字面值）**

| Token | 亮色 | 暗色 | 用途 |
| --- | --- | --- | --- |
| `--app-hover-fill` | `rgb(var(--app-text) / 0.04)` | `rgb(var(--app-text) / 0.06)` | 非强调面的通用 hover 底 |
| `--app-press-fill` | `rgb(var(--app-text) / 0.08)` | `rgb(var(--app-text) / 0.12)` | active / 按压底 |
| `--app-selected-fill` | `rgb(var(--app-accent) / 0.08)` | `rgb(var(--app-accent) / 0.14)` | 选中 / 当前任务行的强调底（区别于 `--app-accent-soft` 的实心浅底，用于卡片内选中） |

**语义色保持**：`--app-accent-soft`（当前任务行青绿浅底 + 文字标签）、`--app-pause`（暂停红）、`--app-danger-solid` + `--app-danger-solid-fg`（危险实心 + 二次确认）、`--app-warning`（逾期 / 待处理）、`--app-success`（已完成 / 运行）。对比度下限沿用 v0.12.86：正文 ≥7:1、次要 / 辅助 / 成功 / 危险 ≥4.5:1、实心按钮标签对底 ≥4.5:1、暂停红 ≥3:1。

**色彩使用纪律（不变）**：强调色只用于导航、主操作、选中态、状态点与有数据的柱；暂停红只出现在状态与损耗，不画成常驻区间；无玻璃拟态、无霓虹描边、无大面积渐变。

### 1.2 层级（Elevation）

桌面端不靠投影堆层级，靠「表面色 + 1px 发丝线」区分。三层就够：

| 层 | 表现 | 消费方 |
| --- | --- | --- |
| L0 画布 | `--app-canvas`，无边界 | 页面底、三栏工作台底 |
| L1 表面 | `--app-surface` + 1px `--app-border` | 任务行卡片、看板卡、分组面板 |
| L2 浮层 | `--app-surface` + 1px 边 + 单层投影 | 右键菜单、工具提示、确认弹窗、抽屉 |

阴影只出现在 L2（浮层）与原生窗口（mini），内容面不用 blur / 发光 / 装饰渐变。卡片圆角继续从 `--radius-*` 阶梯取值（桌面档 `4 / 7 / 10 / 14 / 18 / 22 / 26px`，`--radius-pill 999px`、`--radius-circle 50%`）。

### 1.3 留白（Spacing）

基础步长 **4px**，桌面主窗使用以下阶梯（新增 `20 / 40 / 48` 三档以支撑密度策略）：

```
4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 48   （单位 px）
```

| 场景 | 建议值 |
| --- | --- |
| 页面左右页边距（`view-console` 与主体） | 24px；窗口 <980px 收为 16px |
| 三栏之间的分隔沟 | 24px（导航｜列表｜详情） |
| 卡片内边距（舒适 / 紧凑） | 20px / 16px |
| 卡片之间间隙（看板栅格 gutter） | 16px |
| 任务行之间行距 | 2px（沿用 v1.5.2，行是独立圆角卡片） |
| 分组头与列表间距 | 12px 上、8px 下 |

### 1.4 字体排印

字体族八套界面字体 + `JetBrains Mono`（数字 / 账本 / 计时）继续由 `--font-ui` / `--font-number` 派生，不新增字体包。主窗排印基线 **14px / 1.55**，唯一信息字号下限 **11px**，10px 仅给非核心辅助标签。所有时间 / 统计数字 `tabular-nums`，`letter-spacing` 不得为负。

| 层级 | 字号 / 行高 | 字重 | 字距 | 用途 |
| --- | --- | --- | --- | --- |
| 工位横幅 kicker | 10.5px / 14px | 600 | +0.06em | 「功能 · 副题」大写感标签 |
| 状态词 / 实时读数 | 13px / 18px | 600 | 0 | 横幅中段当前状态、计数 |
| 卡片标题 | 15px / 20px | 600 | 0 | 看板卡标题、详情栏标题 |
| 正文 | 14px / 22px（1.55） | 400 | 0 | 任务标题、说明、列表正文 |
| 辅助正文 | 13px / 20px | 400 | 0 | 日期、清单名、次要元信息 |
| meta / 微标签 | 11px / 16px | 500 | 0 | 计数、图例、胶囊小字 |
| diag | 10px / 14px | 500 | 0 | 诊断行、刻度最小字 |
| 时间读数 | 等宽，tabular-nums | 600 | 0 | 卡片 KPI 读数、账本时长 |

## 2. 布局系统

### 2.1 任务页信息架构（三栏工作台，骨架不变）

```
┌ 工位横幅 58px：视图身份｜全局计数｜刷新/新建操作 ┐
├──────────┬─────────────────────────┬──────────┤
│ 清单导航  │        执行列表          │  详情栏   │
│ 236px    │        1fr              │  360px   │
└──────────┴─────────────────────────┴──────────┘
```

- **清单导航列（236px）**：收件箱固定首行；普通清单独立设色 / 重命名；聚合视图（全部 / 已完成）只读。每行 = 色点 + 名称 + 计数（计数加载中显 `—`，不显示 0）。
- **执行列表（1fr）**：搜索 / 新建并成一行；任务行是独立圆角卡片（无横向分割线，2px 行距）；行内「清单标签」「今天 / 逾期」实心胶囊、「开始专注」快捷胶囊 hover / 焦点时渐显。
- **详情栏（≥1200px）**：点 / 聚焦行即选中，选中行右缘 2px 强调色连接刻度指向详情栏；无显式选中回落当前专注任务。只呈现清单已有字段（清单、父任务面包屑、优先级文字、截止、标签、子任务预览）+「开始专注 / 关联到当前片段」与完成 / 恢复两个独立动作。
- **宽度断点**：<1200px 详情栏退为抽屉 / 底部面板；980×660 为最小地板（`MAIN_WINDOW_MIN_SIZE`），该尺寸下三栏仍可读、无横向溢出。

### 2.2 看板页信息架构（12 栅格 + 右侧账本）

```
┌ 工位横幅 58px：范围身份｜范围预设/单日导航｜刷新状态 ┐
├──────────────────────────────┬──────────────────┤
│        12 栅格分析画布         │   账本阅读列      │
│  hero(12) / rhythm(12) /     │  408px(默认)     │
│  donut(5) + ranking(7) /     │  440px(≥1500)    │
│  heatmap(12)                 │  480px(≥1700)    │
└──────────────────────────────┴──────────────────┘
```

- 五卡顺序固定：`tileHero(span-12) → tileRhythm(span-12) → tileDonut(span-5) + tileRanking(span-7) → tileHeatmap(span-12)`；卡片内部也用 12 栅格。
- 卡片独立圆角细边、**无包裹所有卡片的外层方框**（v1.5.0），无鼠标光斑、无拟物材质。
- 账本列 ≥1240px 独立滚动、头部粘顶；1240px 以下回落单列顺读；<980px 账本进首屏抽屉入口。
- 两条分隔线（导航｜主体｜账本）可鼠标拖动、键盘方向键 / Home / End 微调、双击复位，每页单独记住偏好。

### 2.3 网格与断点

| 断点 | 任务页 | 看板页 |
| --- | --- | --- |
| ≥1700px | 三栏，详情 360px，列表列宽自动 | 账本 480px，五卡全宽 |
| 1240–1699px | 三栏 | 画布 + 账本（408–440px）双栏独立滚动 |
| 1080–1239px | 三栏，详情 360px | 单列顺读 + 账本沉底 / 抽屉 |
| 980–1079px | 列表 + 详情抽屉 | 单列 + 首屏账本入口 |
| <980px | 单列 + 详情抽屉 | 单列 + 抽屉 |

栅格 gutter **16px**，卡片内栅格 gutter **12px**。所有数值从共享断点（CSS px，`linear-workbench.css`）派生，不新增 JS 布局常量。

### 2.4 密度策略

新增「舒适 / 紧凑」两档（设置 → 外观内提供，默认舒适），只改行高与内边距，不改信息结构：

| 维度 | 舒适（默认） | 紧凑 |
| --- | --- | --- |
| 任务行最小高 | 56px | 44px |
| 任务行内边距 | 12px 16px | 8px 12px |
| 看板卡内边距 | 20px | 16px |
| 列表分组头高 | 32px | 24px |
| 详情栏字段行距 | 12px | 8px |

紧凑档不得让任意可读文字 <11px、可操作命中区 <48×48px（桌面鼠标 / 触控双标准）。

## 3. 动效规范（核心诉求：丝滑、轻量、不卡顿）

### 3.1 缓动曲线（四条，统一到 token）

| Token | cubic-bezier | 语义 | 现状 |
| --- | --- | --- | --- |
| `--ease-enter` | `cubic-bezier(0.16, 1, 0.3, 1)` | expo-out，入场 / 显现（快起、稳落） | 已有 `--ease-out-expo` |
| `--ease-exit` | `cubic-bezier(0.4, 0, 1, 1)` | 加速离开（快速淡出，不拖尾） | **新增** |
| `--ease-standard` | `cubic-bezier(0.4, 0, 0.2, 1)` | 位移 / 排序 / 状态切换 | 已有 |
| `--ease-emphasis` | `cubic-bezier(0.34, 1.4, 0.64, 1)` | back-out，强调弹跳（勾选、吸附） | 已有 `--ease-spring` |

弹层（菜单 / 提示 / 确认弹窗）继续用 framer-motion spring `stiffness 380, damping 30`，与 CSS 同源。CSS 过渡与 framer-motion 动画共用这组曲线，**不另造第三套缓动**。

### 3.2 时长梯度（三档，收窄即减负）

| 档位 | Token | 现值 | v1.11.0 建议 | 场景 |
| --- | --- | --- | --- | --- |
| 微交互 | `--dur-micro` | 140ms | **120ms** | hover、按下、勾选、焦点环、胶囊渐显 |
| 常规 | `--dur-base` | 240ms | **200ms** | 控件状态切换、卡片入场、行插入 / 重排、选中态 |
| 页面 / 面板 | `--dur-page` | 360ms | **320ms** | 页面切换、抽屉 / 面板、账本滑入 |
| 数字滚动 | `--dur-count` | ≤600ms | 不变 | 统计读数 count-up，一次性完成，不循环 |

理由：时长是切页成本的一部分（v1.6.8 已实证「延迟 = 感知更卡」）。收窄 20 / 40 / 40ms 在「不卡」与「可感知」之间取更轻的一侧；时间之带（130ms 逐秒步进 / 820ms 变焦）与翻页（fold 170 + unfold 190）等专属节奏**不受本表约束**，继续由 FRONTEND_SPEC §3.4 / §6 定义。

### 3.3 进入 / 退出 / 强调 三类动效清单

| 类别 | 场景 | 时长 | 曲线 | 动画属性 | 合成器友好 |
| --- | --- | --- | --- | --- | --- |
| 进入 | 看板五卡入场（stagger 40ms） | 200ms | enter | `opacity` + `translate` | ✅ |
| 进入 | 任务行新行插入 | 200ms | standard | `opacity` + `translate-y 6px` | ✅ |
| 进入 | 详情栏 / 抽屉滑入 | 320ms | enter | `translate-x 8px` + `opacity` | ✅ |
| 进入 | Tooltip / 菜单 / 弹窗 | 120ms | emphasis | `opacity` + `scale(0.98)` | ✅ |
| 退出 | 任务完成勾销 / 行删除 | 200ms | exit | `opacity` + `translate-x 8px` | ✅（高度塌陷见 3.4） |
| 退出 | 卡片 / 面板移除 | 120ms | exit | `opacity` + `scale(0.98)` | ✅ |
| 退出 | 撤销 Toast 消失 | 120ms | exit | `opacity` + `translate-y 4px` | ✅ |
| 强调 | 勾选 pop（1 → 1.08 → 1） | 120ms | emphasis | `scale` | ✅ |
| 强调 | 快捷胶囊 hover 渐显 + 上浮 | 120ms | enter | `opacity` + `translate-y -1px` | ✅ |
| 强调 | 拖拽吸附落位 | 120ms | emphasis | `translate` | ✅ |
| 强调 | 进度环 / 甜甜圈增量 | 200ms | standard | `stroke-dashoffset` | ✅ |
| 强调 | 选中态切换 | 200ms | standard | `background-color` / `border-color` | ⚠️ paint（小面积可接受） |

### 3.4 合成器友好属性白名单与红线

**只动合成器友好属性**（不触发布局 / 重排）：

- `transform` / 独立 `translate` / `rotate` / `scale`（**关键约束沿用 v1.10.8**：看板卡入场 keyframes 必须用独立 `opacity` + `translate`，**不得用 `transform`**——neutral 皮肤段 `transform: none !important` 位于 CSS 动画层之上，会把 keyframes 里的 `transform` 压回 `none`，动画瞬间失效）
- `opacity`
- SVG `stroke-dashoffset` / `stroke-dasharray`（进度环）
- `background-color` / `border-color` / `color`（小面积 paint，允许）

**避免 / 谨慎**（会触发大面积重排或高成本 paint）：

- `width` / `height` / `margin` / `top` / `left` 的过渡 → 行删除的高度塌陷改用「先 200ms 淡出 + 上移，再用一次性 layout 收口」，或 FLIP 定位；禁止对整段列表做逐行 `height` 动画
- `box-shadow` 过渡（paint 成本高，浮层阴影只做一次性出现，不动画）
- 滚动容器上的 `filter` / `backdrop-filter`（桌面同样禁止）
- 全屏或整页 `transform` / `filter`（全屏页面不动画 transform / filter，沿用手接清单红线）

**性能红线（桌面沿用）**：单视图 DOM ≤4000 节点；活跃合成层 ≤20；导航点击 p75 ≤100ms、INP p75 ≤200ms（目标值，非棘轮阈值）；时间之带是全局唯一持续运动元素，其余动效只出现在状态转换、结束后立即移除动画层。

### 3.5 reduced-motion 全局降级

每条动效都带独立 `prefers-reduced-motion` 分支：入场 / 退出 / 强调一律降为 **140ms 纯透明度**或静态提交（看板卡沿用 v1.10.8 的 `stats-tile-in-fade`：140ms 零阶梯零位移）。降级后顺序 / 状态 / 数值三者不丢失，运行中切换系统偏好立即生效。时间之带与仪表的专属降级见 §3.4 / §6。

## 4. PC 专属交互

### 4.1 键盘

- **焦点环统一**：所有可聚焦元素 `:focus-visible` 用 2px `--app-accent` 描边 + 2px 外偏移（搜索框、任务行、按钮、分段控制、卡片可聚焦区），瞬时显示、不做动画。
- **任务列表**：`↑ / ↓` 在行间移动并同步选中详情；`Enter` 打开详情或触发主操作；`Space` 勾选 / 取消完成；`Alt + ↑ / ↓` 调整主任务顺序（拖动排序的键盘等价，v1.5.1）；`Esc` 关闭抽屉 / 菜单 / 详情并归还焦点。
- **看板**：分隔线 `← / →`（或 `Home / End`）微调、双击复位；范围切换 `← / →` 单日翻页；图表热点可 `Tab` 聚焦并用 `aria-label` 朗读精确值。
- **焦点归还**：抽屉 / 弹窗关闭后焦点回到触发元素；确认弹窗默认聚焦「取消」、Tab 锁在圈内。

### 4.2 鼠标 hover

- hover 只做**渐进显示**（120ms `--ease-enter`）与**中性填充**（`--app-hover-fill`），不改变布局、不弹卡片投影。
- 光标语义：任务行 `pointer`；可拖拽柄 / 分隔线 `grab` → 拖拽中 `grabbing`；仅文本区 `text`；禁用态 `not-allowed`。
- 快捷胶囊（`row-focus-chip`）默认 `opacity: 0 + translate-x 4px + pointer-events: none`，行 `:hover` / `:focus-within` 时 120ms 渐显并接管指针（v1.10.8 已落地，本提案保留并统一到 120ms）。

### 4.3 右键菜单

- 统一 `src/ui` 级菜单组件（发丝边、`--radius-md`、L2 浮层投影），**禁止**原生 `window.*` 对话框（v1.5.3 硬门禁）。
- 任务行右键：`完成/恢复`、`移到清单`（子菜单）、`编辑`、`设优先级`、`删除`（danger + 二次确认）。
- 清单行右键：`重命名`、`设色`、`删除清单`（说明任务与子任务迁入收件箱）。
- 看板卡 / 账本行右键：`复制记录`、`删除记录`（danger，进行中会话禁用并说明）。
- 菜单 Esc / 点击菜单外 / 关闭按钮均可关，打开后聚焦首项、支持 `↑ / ↓` + `Enter`。

### 4.4 拖拽

- **任务排序**：主任务整行 + 独立拖动柄可拖，上 / 下落点可见（2px `--app-accent` 指示线）；自动排序视图拖动后转自定义，隐藏任务相对位置、父子关系、日期不变（v1.5.1）。
- **跨清单移动**：拖到左侧目标清单，悬停 200ms 展开清单；释放即写库并乐观更新，失败回滚。
- **分栏分隔线**：拖动实时预览（120ms 内随指针，不节流到掉帧），吸附到保护正文的最小 / 最大宽；双击复位。
- **红线**：拖拽动画只用 `translate`；拖拽期间暂停行内 hover 动画；原生窗口拖拽（mini 小窗）与业务拖拽互不抢鼠标。

## 6. 落地优先级

**P0 —— 一次迭代内可完成的视觉与动效改动（本提案主交付）**

1. 三档时长梯度收窄：`--dur-micro 140→120`、`--dur-base 240→200`、`--dur-page 360→320`（改 `motion.css` token + 静态兜底值）。
2. 新增 `--ease-exit` 曲线与三条叠加层 token（`--app-hover-fill` / `--app-press-fill` / `--app-selected-fill`），接入任务行、胶囊、看板卡 hover / active / selected。
3. 任务行状态矩阵落地（hover / active / selected / focus-visible / disabled），快捷胶囊统一到 120ms。
4. 看板卡 hover 去投影改细边、焦点环统一、入场 stagger 保持 `translate` 穿透。
5. 密度策略的舒适 / 紧凑两档 token 与首版开关（仅改行高 / 内边距）。

**P1 —— 布局与交互细化**

6. 右键菜单完整落地（任务 / 清单 / 账本行三套菜单 + 子菜单 + 焦点圈）。
7. 分栏分隔线键盘微调 + 双击复位 + 每页记忆偏好的实测。
8. 任务行拖拽排序 / 跨清单移动的落点指示与乐观更新回滚。
9. 看板卡数据更新 `stroke-dashoffset` 过渡 + 范围切换就地 320ms 的实测（不重挂载、不重放入场）。

**P2 —— 深度打磨与跨页一致性**

12. 多显示器混合 DPI、125% / 150% 缩放下动效与断点的实测（配合后端 smoke）。

## 7. 设计决策记录

1. **时长收窄而非加缓动**：v1.6.8 实证「过渡时长是切页成本的一部分，延迟期间用户看到旧页面 = 感知更卡」。因此「更丝滑」不靠更长更柔的缓动，而靠 120 / 200 / 320ms 三档收窄 + 只动合成器友好属性。
2. **保留「translate 而非 transform」约束**：v1.10.8 已实测 neutral 皮肤的 `transform: none !important` 会压掉 keyframes 里的 `transform`。本提案把它从一次性修法升为通用规则（3.4 白名单），避免未来任何入口动效重蹈「动画瞬间失效」。
3. **层级靠表面色 + 发丝线，不靠投影**：延续 §1「禁止圆角卡片墙 / 玻璃拟态」，桌面看板卡 hover 只加粗 1px 边界、不做投影 / 上浮 / 光斑，既守住「丝滑轻量」又避免 paint 成本。
4. **密度策略只改行高与内边距，不改信息结构**：紧凑档不压缩字号下限（≥11px）与命中区（≥48px），否则与无障碍红线冲突。
5. **状态矩阵以「组件」为单位而非「页面」为单位**：任务行、胶囊、看板卡、进度环的 default / hover / active / disabled / loading 状态是跨页复用的最小契约，先统一这层再谈页面级动效，避免每页各写一套 hover。
6. **强调色 / 字体 / 圆角 / 阴影全走 token，不新增运行时依赖**：五个强调色与八套字体是用户偏好，提案零新增 UI 框架、零新增字体包，只补齐缺失的 hover / press / selected 语义 token。
