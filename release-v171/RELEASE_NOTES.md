## 主要变化

- **时间之带新增三种表现**：流线 / 光栅 / 时段，文字分段切换（当前项强调字重 + 底线）；新增视野缩放滑杆与拖动查看时段，画布用真实施工中的 segments / pauses 绘制。桌面时间之带一行未改。
- **主页仪表真实切换**：专注页主读数按设置里的 `timerStyle` 在标准读数与八种 `TimerDial` 之间切换，切一次设置就能在主页看到不同仪表。
- **专注页顶栏状态点**：专注中 / 已暂停时显示已专注时长与状态词，空闲时显示同步状态。
- **任务页看板**：首屏三数字（待办任务 / 今天已完成 / 任务清单）+ 搜索与新建一行 + 待办 / 已完成 / 全部三段筛选；任务行 64px、行首 48px 勾选、右侧「专注 →」直接开始本机专注；元信息显示清单与「本机已保存 / 待同步」。
- **统计页看板**：日期范围 + 时间范围分段；有效专注大数字（中文时/分）+ 专注次数 / 平均时长 / 最长连续三项摘要；每日专注细柱与今天的时段轨道（专注/暂停分色）；24 小时轴、精确空档、任务投入、最近记录与会话账本收进页尾「更多明细」折叠区，功能未删。
- **本机可用性修复**：本机运行草稿优先于云端缓存与凭据恢复，恢复完成前禁止开始第二份会话；新建任务以本机耐久提交为保存成功、后台补传并显示待同步数量；动作失败与未确认原因恢复可见文字与读屏播报。
- 桌面 Windows、Electron 主进程、IPC 与同步协议零改动，本轮只改 `src/mobile/` 与其测试。

## 升级提示

- Windows 使用安装器静默覆盖后必须回读卸载注册表与已安装 EXE 版本，并重新启动应用。
- Android 使用同一 APK 执行 `adb install -r`，保留应用数据并逐台回读 `versionName/versionCode`；生产连接只允许 canonical HTTPS authority，不配置 ADB reverse。
- 既有合法 `fl2` 凭据原位升级；如新设备登录 probe 返回 `not-deployed`，应保留旧设备在线并等待 canonical gateway 部署，不清除应用数据。

## 已知限制

- 统计页「有数据」的看板只在本地样本会话下核对过（8 条合成会话、12 小时 48 分），真机真实账本渲染需用户自用一周后复核。
- 任务页「今天已完成」用 `isCompleted && updatedAt ≥ 今天零点` 推导：协议没有 `completedAt` 字段，昨天完成、今天改过标题的任务会被计入。
- 时间之带刻度文字与「现在」游标标签在窄容器仍可能贴近：根因在共享 `TemporalRibbon.tsx`，桌面侧零改动约束下未修（移动端新画布已缓解）。
- 小米超级岛：当前只完成厂商协议选择，通知权限关闭时没有系统岛可见证据，需真机授权后复验；本版不宣称已集成。
- 旧样式层迁移期仍被导入（工程债）：`mobile-parity-base.css` 等 5 张旧表仍由 `main.tsx` 挂载，删除前需先搬 `.sr-only`、`.mobile-topbar` 52px 下限等规则并把契约测试从双轨降单轨。
